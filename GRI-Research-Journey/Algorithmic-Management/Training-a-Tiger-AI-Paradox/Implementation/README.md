## Reproduce

Python 3.10 or newer, standard library only. From this directory:

```bash
python run_baseline.py
python claim_registry.py claim_register.json --output results/dashboard_review_payload.json
```

The first command reruns fourteen existing engine tests, twelve new lineage tests, ZERO fixture verification, source identity checks, and the synthetic duplicate origin comparison. It writes results/baseline.json. The expected result is all_checks_passed true. Review that file for individual commands and logs.

Optional public observation, requiring network access:

```bash
python collect_public_snapshot.py
```

That command replaces results/public_snapshot.json with a fresh point in time observation. It does not test future availability or validate source contents. Preserve the delivered snapshot before rerunning if you need its original observation.
